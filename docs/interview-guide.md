# 五分钟面试讲解与学习验收

这是公开数据学习项目，当前实现由 AI 协作生成和验证。仓库文件、自动化测试、看板产物不自动代表用户本人已经独立理解或实现。面试时应说明协作方式，并能亲自解释、修改和复现关键逻辑；尚未掌握的部分如实说明正在学习，不把生成记录写成已熟练掌握的个人能力。

## 五分钟演示顺序

| 时间 | 讲什么 | 出示材料 | 需要自己解释清楚 |
|---|---|---|---|
| 0:00—0:45 | 运营负责人关心经营变化、配送与评分、州调查顺序 | 指标字典和窗口配置 | 为什么已交付商品金额不含运费，为什么不是收入；窗口为何从2017年2月到2018年7月 |
| 0:45—1:45 | 订单、明细、支付、评价的不同粒度 | 两事实三维模型图；`01_facts.sql` 的聚合CTE | 一个订单多商品、多支付、多评价时直接连接为何重复金额；客户ID与唯一客户ID区别 |
| 1:45—2:45 | 选择一段 SQL 展示技术判断 | Q02分解或Q07交集比较；相应运行CSV | 连续月份与LAG、零分母、分解顺序；或物流/评分联合样本为何必要 |
| 2:45—3:45 | 展示两页报表，改变购买日期或客户州 | 已实机验证的Desktop报表及对应SQL/DAX记录 | 筛选后重新汇总分子分母，品类只影响明细金额构成；没有Desktop实测证据时只讲工程结构 |
| 3:45—4:30 | 讲一项由实际输出支持的观察 | 结论报告中已有证据和SQL入口 | 明确对象、窗口、分子分母及限制，不预设“业绩下降”或“配送导致差评” |
| 4:30—5:00 | 说明局限和下一步调查 | 质量报告、复购附表 | 没有退款/成本/流量，相关性非因果；需要什么新数据才能进一步验证 |

选择一项自己最熟悉的 SQL，不必在五分钟内逐条朗读十个查询。实际观察与数字从已审核报告读取，不能背用提案中的计划或未经核验的预期。没有业务干预证据，不说“提升营收”“降低退款率”或“优化后提高评分”。

## 三个可以手算的例子

**金额重复。** 一订单两条明细价格为 60、40，另有两条支付、两条评价；商品金额应为 100，不含运费。先按订单聚合明细/支付，按规则选一条评价，再连接订单。自己能画出直接连接扩成多行的过程，并解释为什么不是给最终大表随意 `DISTINCT` 就能正确修复。

**月度分解。** 上月 10 单、客单价 100，本月 12 单、客单价 110。金额从 1000 到 1320，差 320；订单数贡献 `(12−10)×100=200`，客单价贡献 `12×(110−100)=120`。这是算术分解，先后顺序决定分配，不证明业务原因。空月客单价没有定义，不能把它填零后强行分解。

**复购边界。** 首次观测购买在2月1日10:00，同一时刻另一订单不算严格更晚的复购；另一不同订单恰好在首次时间加30天计入，超过1秒不计。先合并等时事件再找下一事件，避免遗漏后面的有效复购；首次加30天晚于观察截止的客户不能进入分母。`customer_unique_id` 才能关联同客户不同订单。

## 高频追问

| 问题 | 回答必须包含的判断 |
|---|---|
| 为什么不用支付总额当成交额？ | 支付与商品加运费可能有差异；本项目先定义商品金额口径，支付只作质量核对 |
| 为什么实际送达时间晚于预计时间仍可能准时？ | 预计时间常是午夜；比较自然日，同预计日送达算准时 |
| 物流缺失订单怎么处理？ | 保留经营金额；退出不具备字段的物流样本，披露日期和交集覆盖 |
| 延迟组差评高能证明延迟导致差评吗？ | 不能；构成、未观测因素和提前回答都会影响比较，需分月/州及敏感性对照 |
| 为什么州比例不能直接平均？ | 不同州分母不同，汇总应累加分子分母后相除 |
| 为什么品类不关联订单事实？ | 混合品类订单可能重复；当前全局日期/州可共用，品类只解释明细金额构成 |
| 复购为什么叫“首次观测”？ | 数据窗口外历史未知；无法确认真实新客户或完整生命周期 |
| 工程能生成，为什么还要Desktop验收？ | 文件格式检查和CSV预期不证明真实刷新、DAX筛选上下文、交互及PBIX保存成功 |

## 用户本人能力验收

使用简历模板前，用户应能在新环境按复现文档运行，解释业务键、样本分母和窗口选择；亲自修改至少一条 SQL 并说明结果变化；手算上述分解和复购边界；在 Desktop 完成日期/州筛选并与同口径 SQL 对账。AI 协作可以帮助实现和审查，但这些现场解释与操作不能由仓库测试替代。

尚未完成上述理解和操作时，可以写“正在学习并复现 Olist 公开数据分析项目”，不写“独立完成完整 BI 系统”或“熟练掌握 SQL/Power BI”。项目通过完整产物验收后，也仍需分别确认本人掌握的范围。
